Locations come from N2's injected registry. After a ready open, call `authorize` with a subset of policy owners and commands. Capabilities are opaque, volatile and instance-bound. Admission is enforced inside the existing repository queue and JSON publication boundary. Private bindings follow the storage object, port and owned lease; reconstructed facades, foreign tickets, captured permits and mutable public options cannot remove the gate. The bootstrap allowance exists only during an explicit empty-authority creation and is sealed after that attempt. Standalone core behavior is retained.

Each normal private receipt binds the canonical native command and `itacan-native-writer-v1` coordination evidence: version, full stable-request digest, authority, affected partition guards, registry/identity/inventory/Phase pins. No capability, epoch, lock token or physical path is persisted there. This is a versioned receipt contract, not a new repository schema/store. Existing receipts remain compatible.

Identical permitted replay returns the original publication result with `replayed:true` and creates no task, Step, event or successor. Changed stable evidence is `OPERATION_CONFLICT`. Replay still requires current authority, capability, ready state and fences before receipt lookup; stale original revision/pin guards are not applied again to a committed replay. New mutations require exact current guards.

Outcomes are detached private objects: committed, rejected, cancelled or uncertain. They contain IDs/revisions and bounded codes, never full native carriers or receipts. Publication/acknowledgement uncertainty holds the original request. Other intents are blocked; changed evidence for that operation conflicts while uncertainty remains explicit. Reconcile the exact authority and retry the identical operation. An external head change may require explicit close/open first. An absent receipt alone does not authorize regeneration. A validated intact unchanged prior head can establish an unpublished attempt; known fallback or unprovable recovery cannot.

Cancellation is effective only before publication. Accepted queued work drains on close while root, lease, scope and evidence remain valid; new admission stops. Reopen requires new capabilities. Dispose delegates to N2's cleanup and retains failed-cleanup behavior. Invalidation/read results are observations, not leases.

Only existing native atomic primitives are admitted. Ordinary creation cannot inject source clocks, migration/capture provenance or source envelopes. Current-content structural edits require explicit N1-C guards and an empty `appendOriginals` list. Cross-owner moves, historical append/import, arbitrary callbacks, generic execution, compound editor saves, clear-completed and planning-object lifecycle are unsupported. No request falls back to Markdown or another authority.

Parent and Step events remain independent. Recurrence uses unchanged B1/B2 commands, calculators, templates and immutable generation outcomes. Recompletion evaluates the current event and reuses the spent successor. Imported checked state remains historical; actual F1/F2 evidence still requires genuine completion plus the selected causal gate. Native order cannot prove an independent Oath save. No Oath persistence extension or latch repair is implemented.

Tests use actual native implementations under a Temp filesystem guard. Runtime has no production construction or transport integration. Claims cover cooperative local admission/persistence and observed process interruptions, not hostile code, power loss, cloud rollback, distributed uniqueness, whole-directory rollback detection or cross-store atomicity.
